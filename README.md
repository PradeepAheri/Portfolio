# Portfolio
Portfolio Website Description

This project is a futuristic neon-themed portfolio website developed using HTML, CSS, and JavaScript. The website is designed to showcase personal information, technical skills, and academic projects in an interactive and visually appealing manner.

The portfolio represents Pradeep, a 1st Year 2nd Semester AIML student from Reva University with interests in Python programming, C programming, graphics programming, and IoT technologies.

The website contains multiple sections including Home, About, Skills, Projects, and Contact. It features smooth animations, glowing neon effects, hover interactions, responsive design, and a custom animated cursor to improve user experience.

Key features of the project include:

- Neon futuristic UI design
- Responsive layout for mobile and desktop
- Interactive hover animations
- Animated glowing background effects
- Skill showcase cards
- Academic project display section
- Contact form interface
- Smooth scrolling animations
- Custom cursor effect

Technologies Used:

- HTML for webpage structure
- CSS for styling and animations
- JavaScript for interactivity and dynamic effects

Academic Projects Displayed:

1. Smart Expense Tracker using Python
2. Graphic Design Project using C
3. IoT Weather Monitoring System

This portfolio website demonstrates front-end web development skills and modern UI/UX design concepts.
